Lab Instructions & Forensic Reference Guide

1. How to Perform the Hands-On Lab

  1. SQL Injection Attack: Go to Target Application -> Catalog Search. Try the payload:
    ' UNION SELECT 1,username,password,email,role FROM users-- This extracts the hidden user database and displays the admin secret flag! Then switch to the SOC SIEM Console to view the generated HTTP GET log with decoded SQL keywords.
  2. Cross-Site Scripting (XSS) Attack: In either Catalog Search (Reflected) or Feedback Board (Stored), submit:
    <script>alert('XSS')</script> Observe the execution modal revealing the XSS flag, and inspect the resulting log in the SIEM.
  3. Authentication Brute Force Attack: Go to Target Application -> Login or Attack Simulator. Click "Run Hydra Brute Force Burst". Watch the stream of 401s followed by the cracked password (dragon123) with status 302!
  4. Inspect Telemetry in SIEM: Switch to the SOC SIEM Console to filter by IP, status code, or rule, and click "Inspect" on any log to see decoded payloads and forensic breakdowns.

2. Common URL Encodings in Web Logs

%27 = Single Quote (')
%22 = Double Quote (")
%3C = Less Than (<)
%3E = Greater Than (>)
%20 = Space ( )
%2D%2D = SQL Comment (--)
%23 = Hash Comment (#)
%2527 = Double Encoded '

3. SIEM Search Query Syntax

status:401 Filter failed authentication events
uri:*union* Search for UNION SELECT in URI
ip:198.51.100.44 Filter logs by specific threat actor IP
rule:RULE-SEC-001 Filter by specific SIEM detection rule
