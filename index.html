Lab Instructions & Forensic Reference Guide

1. How to Perform the Hands-On Lab

  1. SQL Injection Attack: Open the Web Application tab. In the Search Bar, test an unescaped single quote ' (causes database error 500), then inject a UNION SELECT query:
    ' UNION SELECT 1,username,password_hash,email,role FROM users-- This exfiltrates the user database and reveals Flag #1: BLITZ{5ql1_3xf1ltr4t10n_k9x27p4}. Switch to the SOC SIEM Log Monitor to inspect the logged GET /api/search?q= request line and status code 500/200.
  2. Directory Traversal Attack: In the Web Application, go to Document Center. In the filename input, escape the web root to access internal system secrets:
    ../../../../system/secrets.env This exposes the server environment file with Flag #2: BLITZ{p4th_tr4v3rs4l_f1l3_r34d_8a3d1}. Also test ../../../../etc/passwd and view the path traversal IoCs (../) recorded in the SIEM access logs.
  3. Cross-Site Scripting (XSS) Attack: In the Web Application search bar, enter an executable script payload:
    <script>alert('XSS')</script> Observe the script execution in the browser context revealing Flag #3: BLITZ{x55_d0m_3x3cut10n_9c417e2}, then inspect the logged raw URL percent encoding (%3C) in the SOC SIEM console.
  4. Employee SSO Login: Test authentication with username sec_admin or test SQLi authentication bypass ' OR '1'='1. Observe real POST /auth/login logs with request bodies captured in the SIEM.
  5. Analyze SIEM Telemetry: Switch to the SOC SIEM Log Monitor to view the live log stream, status code histogram, and inspect raw logs vs. decoded parameters.

2. Common URL Encodings in Web Logs

%27 = Single Quote (')
%22 = Double Quote (")
%3C = Less Than (<)
%3E = Greater Than (>)
%20 = Space ( )
%2D%2D = SQL Comment (--)
%23 = Hash Comment (#)
%2e%2e = Dot-Dot (..)
