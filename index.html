2. Common URL Encodings in Web Logs

%27 = Single Quote (')
%22 = Double Quote (")
%3C = Less Than (<)
%3E = Greater Than (>)
%20 = Space ( )
%2D%2D = SQL Comment (--)
%23 = Hash Comment (#)
%3D = Equals (=)
